### Task 4: Modalità (Normale / Risparmio / Notte)

**Files:** Create `web/src/lamp-mode.ts`; Modify `device.ts`, `components/DeviceLayer.tsx`, `pages/KioskPage.tsx`, `App.tsx`.
- `autoState(prefs, battery, landscape, now) → { eco: boolean, night: boolean }`: funzione pura, che riusa `ecoActive` e la regola `autoNight` del Kiosk.
- `useLampMode()` restituisce `{ mode, cycle() }`:
  - override in `localStorage` (`hubitat:lamp`) con la firma dell'`autoState` del momento;
  - se la firma cambia, l'override si cancella;
  - `cycle()`: Normale → Risparmio → Notte → Normale.
- `html.eco` viene da `mode === 'eco' || mode === 'night'` (in notte la pagina è comunque spenta).
- Notte: `KioskPage` apre `NightStand` quando `mode === 'night'`; fuori dal kiosk (PC/telefono) `cycle()` verso Notte apre `/notte`.
- [ ] Logica pura verificata con uno script `node` di prova nel ledger (casi: batteria bassa, override, cambio firma, notte in carica); la webapp non ha test runner.
