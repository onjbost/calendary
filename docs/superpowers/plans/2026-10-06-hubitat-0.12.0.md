# Hubitat 0.12.0 — modulo Viaggi — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Sezione "🧳 Viaggi" di Hubitat: viaggi con tratte e programma, scritti nel calendario come eventi con orario + strisce dei giorni, promemoria, meteo della destinazione (la valigia arriva in 0.12.1).

**Architecture:** Modulo isolato in `server/src/trips/` e `web/src/trips/`; parla con il calendario solo da `calendar-port.js` (eventi `planId: trip:<id>`, modalità viaggio). Le strisce dei giorni sono calcolate, non salvate.

**Tech Stack:** Node 24, Fastify 5, node:sqlite, node:test; React 19 + Vite + TypeScript.

**Spec:** `docs/superpowers/specs/2026-10-06-viaggi-design.md` (§3-§8, §10, §11; §9 è 0.12.1).

## Global Constraints

- Testi in italiano; codice e commenti in inglese come il resto del repo.
- Nessuna chiamata di rete reale nei test (fetch finto per Open-Meteo).
- Il resto di Hubitat importa dal modulo solo: `registerTripRoutes`, `startTrips`, `checkTripReminders`, `tripDaySummary` (server); `TripsPage`, `TripPage`, `DayStrips`/`useTripDays`, `TripCard`, `tripFromEvent` (web).
- Colore dei viaggi `#38bdf8`. Etichette: beach 🏖️ Mare, hiking ⛰️ Montagna/escursione, dinner 🍽️ Cena elegante, work 💼 Lavoro, sport 🏃 Sport, city 🏙️ Città, party 🎉 Serata, other 📍 Altro. Mezzi: plane ✈️, train 🚆, bus 🚌, car 🚗, ferry ⛴️. Bagagli: backpack_s, backpack_l, cabin, suitcase.
- Versione `calendary/config.yaml` → 0.12.0.

## Review Focus

1. Modifica di un evento `trip:` dal calendario mentre il modulo salva lo stesso evento → nessun ciclo (il modulo non reagisce alle proprie scritture). Test in Task 2.
2. Viaggio che attraversa il cambio dell'ora legale (fine ottobre) → strisce e promemoria calcolati su date locali, non su +24 h. Test in Task 3 e Task 5.
3. Server riavviato dopo l'orario del promemoria → il promemoria parte una volta sola, e non se la partenza è già passata. Test in Task 5.
4. Città con apostrofi/accenti ("L'Aquila", "Forlì") nel geocoding → query codificata correttamente. Test in Task 4.
5. Eliminare un viaggio con modalità viaggio e eventi → spariscono periodo ed eventi, nessun evento orfano. Test in Task 2.
